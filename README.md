# Координата (Coordinate)
Учебный калькулятор по топографии для студентов 1 курса (географического факультета МГУ). Помогает с переводом координат, сближением меридианов, поиском азимутов, а также номенклатурой.

A topography calculator for first-year students (Faculty of Geography, Moscow State University). It helps with coordinate conversion, meridian convergence, azimuth calculations, and nomenclature.
